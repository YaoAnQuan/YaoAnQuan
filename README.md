# 药安全 · 查药助手

一个面向全家的移动端药品查询工具:支持多种方式登录、批准文号查验、拍照 AI 识别药盒、按年龄段的药品分类提示、语音朗读结果、服药提醒和家人共享(添加家人、共享数据、吃药相互提醒、相互关怀)。

> 结果仅供参考,最终以[国家药监局官网](https://www.nmpa.gov.cn/)查询为准。

## 功能特性

### 多种登录方式

- **微信登录 / 支付宝登录**(演示环境模拟授权)
- **手机验证码登录**:校验 11 位手机号 + 60 秒倒计时验证码(演示环境显示模拟验证码)
- 登录后头像与昵称显示在页头,可随时退出;用户信息存 localStorage
- 登录是使用「家人共享」的前提

### 家人共享(最多 5 位家人)

- **添加家人**:称呼、关系(爸爸/妈妈/爱人/子女等)、年龄段(儿童/青少年/成人/老年人)
- **共享数据**:所有吃药计划按成员展示互通可见,添加计划时可选择「谁服用」
- **吃药相互提醒**:到点提醒任意家人服药,弹窗/系统通知/语音播报均带成员姓名,并自动写入共享动态「已提醒XX吃药」
- **相互关怀**:一键向家人送上关怀 ❤️;家人动态时间线记录登录、添加计划、提醒、关怀等事件
- 家庭组最多 6 人(自己 + 5 位家人)

### 查药 / 鉴别真伪

- **文号查验**:输入批准文号,本地规则引擎即时校验
  - `国药准字 H/Z/S/J + 8 位数字` → 格式符合药品标准(H=化学药、Z=中成药、S=生物药、J=进口分包装)
  - `国食健字` / `食健备` → 保健食品(非药品)
  - `SC + 14 位数字` → 普通食品
  - 含「根治、特效、祖传、偏方、秘方、神药」等违规用语 → 疑似虚假宣传
  - 格式错误 / 无法识别 → 高度警惕
- **拍照识别**:拍摄或从相册选择药盒照片,通过 DMXAPI 视觉大模型识别包装文字,自动提取批准文号、生产日期、有效期等信息,并结合本地规则引擎分析安全性(含过期检测、可疑宣传用语检测)
- **结果三色分级**:绿(安全)/ 黄(请注意)/ 红(危险),大字卡片展示,附「AI 识别详情」可展开查看

### 药品分类与适龄用药提示

查药与拍照识别的结果卡片中自动追加「药品分类与适龄提示」,支持按「为谁查药」选择年龄段(儿童/青少年/成人/老年人),保存吃药计划时也会按家人年龄段自动核查。分类知识库依据公开权威资料整理(人民网《十类常用药儿童禁忌多》、央视网解热镇痛药儿童专家共识报道、中国医药信息查询平台等):

- **儿童用药**(小儿/氨酚黄那敏/美林/泰诺林):按体重计算剂量、退热首选对乙酰氨基酚或布洛芬且每日不超 2 克
- **儿童用药红线**:阿司匹林(瑞氏综合征)、尼美舒利(12岁以下)、安乃近(18岁以下)、氟喹诺酮类 XX沙星(18岁以下)、四环素类(8岁以下)、氨基糖苷类庆大霉素等(6岁以下,耳肾毒性)、氯霉素、洛哌丁胺、异丙嗪等 — 命中即红色强提醒
- **感冒用药**:复方感冒药不可叠加同服(对乙酰氨基酚肝损伤)、氯苯那敏嗜睡禁驾驶
- **激素类**(泼尼松/地塞米松/甲泼尼龙等):严禁突然停药须遵医嘱减量、建议早晨服用、长期用监测血糖血压骨密度;儿童影响生长发育、老年人易高血压糖尿病骨质疏松
- **心血管类**:肠溶阿司匹林不可嚼碎、他汀晚间服、降压药不可随意停
- **降糖类 / 抗生素类**(头孢与甲硝唑禁酒双硫仑反应、按疗程服用)/ 消化类 / 维生素营养类
- **保健食品**:不能替代药品;**普通食品(SC)**:无任何治疗功能,宣传治病涉嫌违法

### 语音朗读

- 查验结果一键朗读(Web Speech API)
- 拍照识别完成后自动朗读分析结果
- 适合视力不佳的中老年用户

### 吃药提醒

- 自定义服药计划:药名、每次剂量、多个服用时间、服用成员
- 计划保存在浏览器 localStorage,无需登录
- 到点自动提醒:页面弹窗 + 系统通知 + 语音播报
- 支持「过 10 分钟再提醒」贪睡功能
- 每 15 秒检测一次到点时间

### 适老化设计

- 大字体(正文 20px)、高对比度配色、大按钮
- 480px 移动端优先布局,适配小屏
- 拍照前预览确认,支持重新拍摄
- 自动处理手机照片 EXIF 旋转方向,压缩至 1280px 再上传

## 技术架构

```
浏览器 (index.html)
   │  POST /api/chat
   ▼
Vercel Serverless Function (api/chat.js)
   │  HTTPS 转发 (Bearer API_KEY)
   ▼
DMXAPI (www.dmxapi.cn /v1/chat/completions, gpt-4o)
```

- **前端**:纯静态单页 `index.html`(原生 HTML/CSS/JS,无框架、无构建步骤)
- **后端**:`api/chat.js` Vercel Serverless 函数,统一代理 DMXAPI 请求
- **安全**:API Key 仅保存在 Vercel 服务端环境变量中,不出现在浏览器或网络请求里
- **AI 能力**:DMXAPI `gpt-4o` 视觉模型识别药盒文字(JSON 输出),规则引擎本地二次分析

## 目录结构

```
YaoAnQuan/
├── index.html      # 前端单页应用(查药 + 拍照识别 + 服药提醒)
└── api/
    └── chat.js     # Vercel Serverless 函数,代理 DMXAPI 聊天接口
```

## 部署(Vercel)

1. 将本项目导入 [Vercel](https://vercel.com)(直接关联 GitHub 仓库即可,`api/` 目录会被自动识别为 Serverless Functions)
2. 在项目设置中添加环境变量:

   | 变量名 | 说明 |
   | --- | --- |
   | `API_KEY` | DMXAPI 平台(https://www.dmxapi.cn)的 API Key |

3. 部署完成后即可访问。页面右上角 ⚙️ 可查看云端 API 状态并测试连接。

## 本地开发

无需构建,直接用任意静态服务器打开即可(推荐 `npx serve .` 或 VS Code Live Server)。

> 注意:本地静态托管时 `/api/chat` 代理不可用,拍照识别需部署到 Vercel 后使用;文号查验和吃药提醒为纯前端功能,本地即可完整体验。

## 已知限制

- 吃药提醒依赖页面保持打开(纯前端定时检测),关闭页面后不会提醒
- 药品真伪最终结论请以国家药监局官网备案信息为准,本工具仅做格式校验与风险提示
